# Code Review Assistant

A smart code review tool using Git, GPT-4, and LangChain.

## Features
- Analyze git diffs or PRs
- Highlight logic bugs, bad naming, security concerns, code smells
- Summarize code changes
- Suggest improvements
- Output markdown-friendly comments

## Tech Stack
- Python
- LangChain
- OpenAI GPT-4
- Git CLI

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Run the CLI: `python main.py`

## Usage
- Make a code change and commit it
- Run the tool to review the latest diff
